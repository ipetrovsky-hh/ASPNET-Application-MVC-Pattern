РЕпозиторий содержит демонстрационные материалы 
framework ASP.NET MVC architecture pattern
Функционал:
1) приложение открывается в браузере.
2) содержит горизонтальное меню
- Домашняя страница
- Информация
- Связаться
- Оборудование
3) Пункт меню "Обрудование"
Состоит из 3 элементов:
- Список оборудования
- кнопка "Добавить новую строку"
- кнопка "Редактировать строку"
